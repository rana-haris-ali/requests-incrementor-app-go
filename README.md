# Requests Incrementor App (written in Go)

This is a simple Go application that increments a request count in Redis and returns the current count.

This application was developed as part of a Cloud Computing course at the University of Marburg.

# Running the Application

To run the application, you can use Docker Compose:

```bash
docker-compose up
```

This will start the backend and Redis services. The application will be available at `http://localhost:8080`.
